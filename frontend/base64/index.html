Frequently asked questions

What is Base64 encoding used for?

It turns binary data or text into plain ASCII characters so it can travel safely in emails, URLs, JSON or data URIs.

Is Base64 encryption?

No. Anyone can decode Base64 instantly, so never use it to hide passwords or secrets.
