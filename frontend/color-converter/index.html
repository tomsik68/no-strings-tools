Frequently asked questions

How do I convert HEX to RGB?

Type or paste the HEX value (e.g. #3366ff) and the RGB and HSL values appear instantly.

What is HSL?

Hue, saturation and lightness. It makes it easy to create lighter, darker or less saturated versions of a color.

Can I pick a color visually?

Yes. Use the color picker, then copy any format.
