Test keyboard typing speed

This keystroke test measures how fast your keyboard registers key presses. Use it to benchmark your raw typing speed, check keyboard rollover, or spot ghosting. The test runs for a short sliding window and updates keys-per-second, keys-per-minute and an estimated WPM in real time.

Frequently asked questions

How do I test my keyboard speed?

Click the test area and start pressing keys as fast as you can. The tool counts every key press and shows your keys per second, keys per minute and estimated WPM.

What is keyboard ghosting?

Ghosting happens when a keyboard reports a key press you did not make, usually when many keys are held at once. This tool shows the keys currently pressed so you can visually detect unexpected keys.

Can I use this on mobile?

The tool works best with a physical keyboard. On-screen mobile keyboards may not register rapid keystrokes the same way.
