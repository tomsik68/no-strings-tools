Create a Wi-Fi QR code instantly

Generate a free Wi-Fi QR code that lets guests connect by scanning with their phone camera. Enter your network name (SSID), password and security type, then download the QR code as a PNG. Everything stays in your browser — no data is uploaded.

Frequently asked questions

How do I create a QR code for Wi-Fi?

Enter your Wi-Fi network name, password and security type. The QR code updates automatically. You can download it as a PNG to print or share.

Can I make a Wi-Fi QR code without a password?

Yes. Select “None (open network)” from the Security dropdown. The QR code will connect devices without asking for a password.

Is my Wi-Fi password sent to a server?

No. The QR code is generated locally in your browser. Your SSID and password never leave your device.
