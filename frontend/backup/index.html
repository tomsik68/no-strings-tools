    Frequently asked questions

    Where do these tools store my data?

    In your browser's localStorage, on this device only. Nothing is sent to a server.

    How do I move my data to a new computer or browser?

    Download a backup here, copy the JSON file to the other device, and use "Restore from backup". For a live transfer, use Data Sync.

    Will clearing my browser data delete my lists and logs?

    Yes. Clearing site data removes localStorage, so download a backup first.
