Frequently asked questions

How do I convert CSV to JSON?

Paste CSV with a header row and click "CSV → JSON". Each row becomes an object keyed by the headers.

How do I convert JSON to CSV?

Paste a JSON array of objects and click "JSON → CSV".

Is there a file size limit?

No server is involved, so the only limit is your browser's memory.
